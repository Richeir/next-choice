# 前端页面设计

本文档描述 React 前端各页面设计，涵盖 issue 要求的 MVP0 页面。API 调用约定见 [api-design.md](../api-design.md)。

## 1. 页面总览

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | 首页 | 统计指标 + 快速入口 |
| `/stocks` | 股票列表 | 列表 + 排序 + 查询 |
| `/etfs` | ETF 列表 | 列表 + 排序 + 查询 |
| `/stocks/:code` | 股票详情 | 基础信息 + 最后分析结果 |
| `/etfs/:code` | ETF 详情 | 基础信息 + 最后分析结果 |

## 2. 首页 `/`

展示 issue 要求的四类统计指标，并作为各页入口。

- **统计卡片**（调用 `GET /api/stats`）：
  - 收录股票数 `stockCnt`
  - 收录 ETF 数 `etfCnt`
  - 已分析数量 `analyzedCnt`
  - 已分析次数 `analyzedTimes`
- **入口**：跳转股票列表 / ETF 列表的按钮。
- 数据加载时显示 loading，失败显示重试。

## 3. 股票列表 `/stocks`

### 功能
- **关键字查询**：代码或名称模糊匹配（输入框，防抖触发）。
- **条件过滤**：行业、市场（SH/SZ）。
- **排序**：点击表头切换，支持代码/名称/最新收盘/涨跌幅/行业/**买入评级**/评分。
- **分页**：页码 + 每页条数。

### 表格列
| 列 | 来源 | 说明 |
|----|------|------|
| 代码 | `code` | 跳转详情 |
| 名称 | `codeName` | |
| 市场 | `market` | 标签 |
| 行业 | `industry` | |
| 最新收盘 | `lastClose` | 可排序 |
| 涨跌幅 | `lastPctChg` | 涨红跌绿 |
| **买入评级** | `analysis.rating` | 可排序，徽章显示 |
| 评分 | `analysis.score` | 可排序 |

- 评级徽章按档位配色（S+ 最深 → D 最浅）。
- 未分析标的评级列显示"—"。

## 4. ETF 列表 `/etfs`

与股票列表对称：

- 查询：关键字（代码/名称）。
- 过滤：市场。
- 排序：代码/名称/最新收盘/涨跌幅/**买入评级**/评分。
- 列：代码、名称、市场、基金规模 `fundScale`、最新收盘、涨跌幅、评级、评分。

## 5. 股票详情 `/stocks/:code`

### 5.1 基础信息区（`GET /api/stocks/:code`）
- 名称、代码、市场、行业、上市日期、上市状态、最新收盘、涨跌幅、成交额、PE。

### 5.2 最新分析结果区（`GET /api/stocks/:code/analysis` 取第一条）
- **买入评级**徽章、综合评分、信号（BUY/HOLD/SELL）、是否值得买、建议持有天数。
- 分析要点 `note`。
- 详细分析文字 `llmAnalysis`（Markdown 渲染）。
- 分析日期。

### 5.3 K 线图（`GET /api/stocks/:code/kline`）
- 频率切换：日/周/月；复权切换：前复权/不复权。
- 折线或 K 线图展示 close，叠加 MA5/MA20/MA60。

### 5.4 操作
- **触发分析**按钮：`POST /api/stocks/:code/analyze` → 轮询任务 → 完成后刷新分析区。
- 分析历史列表（可展开查看历史评级变化）。

## 6. ETF 详情 `/etfs/:code`

同股票详情，基础信息含基金规模 `fundScale`，K 线/分析区一致。

## 7. 组件与状态

- **数据请求**：Axios 封装于 `src/api/`，统一错误处理。
- **状态管理**：MVP0 用本地 state + React Query（或简单 hook）即可，暂不引入全局状态库。
- **UI 库**：可用 Ant Design 加速表格/表单/徽章（可后续定），或用轻量组件 + Tailwind。
- **加载/错误/空态**：统一 Loading / Error / Empty 组件。
