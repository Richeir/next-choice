## 0. 全局布局

所有页面共享统一布局：

### 顶部横幅
- 浅蓝色背景条，居中文字（如"生存是第一要务"），可配置。

### 导航栏
- **左侧**：黑色圆角方形 Logo（白色字母"M"）+ 品牌名"M·STOCK"
- **中间**：导航链接"首页"、"股票"、"ETF"，当前页加下划线高亮
- **右侧**：数据日期标签（绿色圆点 + "数据日期 2026-08-13"），灰色圆角边框

### 页脚
- 左侧："© 2026 M·STOCK · 数据来自示例源,仅供原型演示"
- 右侧链接：首页 / 股票 / ETF / 使用文档 / 隐私

## 1. 首页 `/`（index.jpg）

### 结构
- **面包屑标签**："— 系统数据"（蓝色小字）
- **页面标题**："股票 / ETF 数据汇总"
- **统计卡片区**：两个并排卡片（各占 50% 宽度），圆角灰色边框

### 统计卡片

| 卡片 | 标题 | 大数字 | 已分析 | 百分比 | 进度条 |
|------|------|--------|--------|--------|--------|
| 左 | "股票 · STOCKS" | 收录股票总数（如 5,348） | "已分析 4,832"（绿色） | 分析覆盖率（如 90.3%，绿色标签） | 蓝色进度条 |
| 右 | "ETF · 交易所基金" | 收录 ETF 总数（如 624） | "已分析 512"（绿色） | 分析覆盖率（如 82.1%，绿色标签） | 蓝色进度条 |

- 大数字：超大字号（约 48px），黑色粗体
- 已分析数：绿色文字
- 百分比标签：绿色背景圆角小标签，右对齐
- 底部进度条：蓝色，宽度 = 已分析/总数

### 数据来源
- `GET /api/stats` → 返回 `stockCnt`、`etfCnt`、`analyzedCnt`、`analyzedTimes`
- 前端计算百分比 = 已分析数 / 总数

## 4. 详情页 `/stocks/:code`（detail.jpg）

以贵州茅台（600519）为例。

### 4.1 面包屑
- "股票 / 白酒 / 600519"（类型 / 行业 / 代码）

### 4.2 头部信息区（左右两栏）

**左栏：**
- 代码 + 状态标签："600519.SH" + 绿色标签"已分析"
- 名称（大字）："贵州茅台"
- 描述行："贵州茅台酒股份有限公司 · 2001-08-27 上市 · 流通市值 2.07 万亿 · 总市值 2.60 万亿"

**右栏（右对齐）：**
- 收盘价（超大字号）："1,654.00"
- 涨跌额 + 涨跌幅（红色/绿色）："-6.94 · -0.42%"
- 时间戳："2026-08-13 收盘 · 15:00 CST"

### 4.3 分析结果卡片（灰色背景）

- 顶部标注："2026-08-13 收盘后生成"
- **左侧**：蓝色圆形评级徽章
  - 大字："A+"
  - 小字："82 / 100"（评分/满分）
- **右侧**：分析摘要文字（多行）
  - 示例："基本面稳健(品牌护城河 + 高 ROE)+ 估值合理偏低(历史百分位 18%)= 长期配置价值。"
  - "短期资金面中性,等待板块轮动催化。"
  - "建议关注 1,580 / 1,520 支撑位,目标价区间 1,720 - 1,820。"

### 4.4 关键指标行（7 个指标并排，灰色边框卡片）

| 指标 | 示例值 |
|------|--------|
| 成交额 | 32.4 亿 |
| 换手率 | 0.18% |
| PE (TTM) | 24.2 |
| PB | 8.6 |
| 总市值 | 2.60 万亿 |
| 52 周高 | 1,789.00 |
| 52 周低 | 1,387.50 |

### 4.5 K 线图区域

- **区间选择器**（右上角）：`1M` | `3M` | `6M`（选中，深色背景） | `1Y` | `3Y` | `5Y`
- **图表类型**：蓝色面积图（收盘价）+ 均线叠加 + 底部成交量柱状图
  - 收盘价：蓝色面积填充
  - MA20：黄色线
  - MA60：灰色线
  - 成交量：底部柱状图，红涨绿跌
- **图例**（图表下方）：收盘价 | MA20 | MA60 | 成交量(红涨绿跌)
- **交互**：hover 显示十字线 + 数值标签（如 "1,622.82"）

### 4.6 数据来源
- 头部 + 关键指标：`GET /api/stocks/:code`
- 分析结果：`GET /api/stocks/:code/analysis`（取最新一条）
- K 线图：`GET /api/stocks/:code/kline?frequency=daily&adjust=qfq&limit=120`

## 6. 视觉规范

| 元素 | 规范 |
|------|------|
| 品牌色 | 蓝色（导航高亮、进度条、主按钮） |
| 涨/跌 | 涨 = 绿色，跌 = 红色（A 股惯例） |
| 状态标签 | "已分析" = 绿色圆角标签，"待分析" = 灰色圆角标签 |
| 评级徽章 | 蓝色圆形，内含评级字母 + 评分 |
| 表格 | 无外边框，行间浅灰分隔线 |
| 筛选栏 | 灰色背景圆角区域 |
| 卡片 | 白色背景 + 浅灰圆角边框 |
| 字体 | 等宽数字（价格/代码），无衬线正文 |
| 分页按钮 | "上一页"灰色、"下一页"蓝色主按钮 |

## 7. 组件与状态

- **数据请求**：Axios 封装于 `src/api/`，统一错误处理
- **状态管理**：MVP0 用本地 state + React Query（或简单 hook），暂不引入全局状态库
- **UI 库**：可用 Ant Design 加速表格/表单/徽章，或用轻量组件 + Tailwind
- **图表**：ECharts 或 Recharts（面积图 + 均线 + 成交量）
- **加载/错误/空态**：统一 Loading / Error / Empty 组件
